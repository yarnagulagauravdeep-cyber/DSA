## 🛠️ How to Run locally

All solutions in this repository are implemented in **C++**. You can compile and run them using any standard C++ compiler (like `g++`).

### Prerequisite
Make sure you have GCC/G++ installed. You can check this by running:
```bash
g++ --version
```

### Compilation & Execution
To run any solution (for example, `RemoveDuplicates.cpp`):

1. Navigate to the specific topic folder:
   ```bash
   cd Arrays
   ```
2. Compile the C++ file:
   ```bash
   g++ RemoveDuplicates.cpp -o RemoveDuplicates
   ```
3. Run the executable:
   - On Windows:
     ```bash
     .\RemoveDuplicates
     ```
   - On Linux/macOS:
     ```bash
     ./RemoveDuplicates
     ```
